# 0.1.0-beta.2

## Summary

This second beta improves daily workstation usability, prescription presentation, accessibility, and engineering/release reliability while preserving the existing clinic workflows and security boundaries.

## Highlights

- Professional responsive clinic workstation redesign with role-aware sidebar and mobile navigation.
- Clearer patient, agenda, consultation, follow-up, prescription, practice-profile, and staff workflows.
- Accessible confirmation dialogs with keyboard focus restoration, including appointment-overlap cancellation.
- Human-readable validation, status, date, action, loading, empty, and error presentation.
- Moroccan/bilingual prescription profile fields, Arabic glyph output in the current versioned template, and authenticated PDF launching.
- Stabilized PostgreSQL integration organization, timezone fixtures, migration validation, and CI checks.

## Engineering quality

- 76 unit tests.
- 64 PostgreSQL integration tests.
- 3 Playwright E2E tests.
- PostgreSQL migration validation, production build verification, security scanning, and GitHub CI/CodeQL checks.

## Upgrade notes

Beta.1 users must apply the two database migrations added after beta.1 before starting beta.2:

```bash
pnpm db:migrate
```

These migrations add the practice-profile and prescription issue-snapshot fields required for the Moroccan/bilingual prescription workflow. Do not recreate an existing database.

## Beta notice

This is beta software. Public demos and repository fixtures use synthetic data only. The application does not automatically provide healthcare regulatory compliance. Real deployments require independent security, legal/compliance, infrastructure, access-control, backup/retention, and operational review.

## Known limitations

- One clinic and one doctor instance; no multi-tenant or multi-doctor operation.
- English application UI; full application RTL localization and complete bidi/shaping support are not implemented.
- Arabic profile fields and Arabic glyph output are supported in the current Moroccan prescription template, but jurisdiction-specific legal formatting remains a deployment responsibility.
- PDFs are regenerated from immutable issue snapshots; exact PDF bytes are not archived.
- No notifications, patient portal, public booking, billing, pharmacy, medication database, interaction checking, clinical recommendations, digital signatures, or signature/stamp images.
- All demo and test fixtures are synthetic and must never be replaced with real patient data.
