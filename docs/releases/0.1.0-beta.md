# Clinic Management 0.1.0-beta.1

## Scope

This first open-source beta contains authentication, doctor/secretary authorization, administrative
patients and appointments, doctor-only consultations and immutable notes, follow-ups, prescriptions,
practice profiles, prescription history/replacements/voiding, and regenerated A4 prescription PDFs.

## Important limitations

- One clinic and one doctor instance; no multi-tenant or multi-doctor operation.
- English UI; Arabic/RTL PDF rendering is deferred.
- PDFs are regenerated from immutable issue snapshots; PDF bytes are not archived.
- No notifications, patient portal, public booking, billing, pharmacy, medication database, interaction
  checking, clinical recommendations, digital signatures, or signature/stamp images.
- Legal prescription formatting and compliance review remain deployment responsibilities.
- All demo and test fixtures are synthetic and must never be replaced with real patient data.

## Operator notes

Run the complete migration chain on a disposable PostgreSQL database, configure independent secrets, and
restore-test encrypted backups before any real deployment. The browser print workflow records PDF
generation/request semantics only; it cannot prove that a physical printer completed a job.
